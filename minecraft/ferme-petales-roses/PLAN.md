# Plan couche par couche

Le nord est en haut (z croissant = sud, x croissant = est).

## Legende

- `S` : Pierre
- `M` : Bloc de mousse
- `=` : Rail
- `>` : Rail propulseur
- `R` : Bloc de redstone
- `h` : Entonnoir
- `C` : Coffre
- `D` : Distributeur
- `p` : Petales roses
- `.` : Poudre de redstone
- `r` : Repeteur
- `c` : Comparateur
